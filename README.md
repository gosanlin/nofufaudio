# nofufaudio #
An opensource Music &amp; Audio Player/Downloader like Spotify or YouTube

Un reproductor de audio &amp; música de código abierto como Spotify o YouTube

# 🚀 ¿Cómo hacer que funcione NofufAudio?


# 💻 WINDOWS
**1**. Instalar mediante el instalador **NofufAudio Setup 1.0.0.exe** o ejecutando el archivo **NofufAudio.exe** de la versión portable.

---

# 🐧 LINUX (CachyOS, Arch...)
**1**. Asegúrate de tener las **dependencias** instaladas en tu sistema:
   * **Arch / CachyOS:** `sudo pacman -S nodejs npm 7z python yt-dlp`

**2**. Abre una terminal en la carpeta donde este el archivo .zip y ejecuta:
```bash
 7z x linux-portable-nofufaudio-1.0.2.zip
 cd nofufaudio
 chmod +x install.sh
 ./install.sh
```
